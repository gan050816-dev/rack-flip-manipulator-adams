# 齿条驱动翻转机械手 ADAMS 虚拟样机

## 项目简介

本仓库保存一套齿条、直齿轮与锥齿轮传动的翻转机械手机构资料，包括 SolidWorks 零件与装配体，以及用于重新建立 ADAMS 虚拟样机的 Parasolid 交换模型。

## 主要内容

- 齿条、直齿轮和锥齿轮传动机构。
- SolidWorks 原始模型与 Parasolid 交换模型。
- 用于重建 ADAMS 约束、接触和驱动关系的技术说明。

## 目录结构

```text
model/Adams 大作业/sw/      SolidWorks 与 Parasolid 模型
docs/                       结构和仿真说明
```

## 环境依赖

- SolidWorks 或兼容 CAD 软件。
- MSC ADAMS，用于重建和运行虚拟样机。

## 使用方法

1. 先在 SolidWorks 中检查装配关系和齿轮、齿条的几何参数。
2. 需要重新导入 ADAMS 时，优先使用 `装配体22.x_t` 等 Parasolid 文件。
3. 在 ADAMS 中重新检查材料、质量、约束、接触参数和驱动函数。
4. 运行仿真后对翻转角、齿条位移、驱动力和约束反力进行复核。

原始 ADAMS 二进制数据库内嵌了创建者姓名、学号和本机绝对路径，因此未纳入公开副本。Parasolid 和原始 CAD 文件用于重建模型，也能降低 ADAMS 版本绑定带来的迁移问题。
