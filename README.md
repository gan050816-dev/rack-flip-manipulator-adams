# 齿条驱动翻转机械手：结构设计与虚拟样机

项目以末端机构约 **180° 翻转**为设计目标，通过齿条、直齿轮和锥齿轮组成传动链，把直线驱动转换为末端翻转运动。工作围绕机械装配和 ADAMS 虚拟样机展开，关注齿条行程、末端转角、驱动力及运动连续性之间的关系。

## 项目成果

形成了包含齿条、直齿轮、锥齿轮及支撑零件的 SolidWorks 装配，并保留整体装配和主要传动件的 Parasolid 交换模型。读者可以从装配结构检查运动传递路径，再按[重建检查指南](docs/model-notes.md)确认 ADAMS 所需的约束、接触与驱动数据。该指南列出重建顺序和待补信息，不包含原工程的完整参数。

当前公开成果侧重**机构结构与虚拟样机重建依据**。约 180° 是原工程记录的目标动作；公开仓库未包含可直接运行的 ADAMS 数据库，也未包含本次重新求解的动力学结果，不能据此认定翻转精度、驱动力或运动平稳性已经复测通过。

## 机构如何工作

```text
齿条直线移动 → 直齿轮转动 → 锥齿轮改变传动方向 → 末端机构翻转
```

- **直线运动转旋转运动：** 齿条与直齿轮啮合，齿条行程决定输入侧转角，需要保持几何参数与啮合方向一致。
- **调整传动方向：** 锥齿轮把运动传至末端翻转机构，装配关系决定各转轴和末端的运动方向。
- **在虚拟样机中检查运动与受力：** 用移动副、转动副和固定副约束自由度，结合驱动函数和齿轮接触，观察齿条位移、翻转角、驱动力与约束反力。

重建时的重点是让自由度、啮合关系与驱动相互一致，并核对接触刚度、阻尼、摩擦和单位体系。单独查看 CAD 几何不能完成这些动力学检查。

## 查看与重建

| 想查看的内容 | 工程入口 |
| --- | --- |
| 机构整体装配 | [装配体22.SLDASM](model/Adams%20大作业/sw/装配体22.SLDASM) |
| 导入其他 CAD 或 ADAMS 的整体几何 | [装配体22.x_t](model/Adams%20大作业/sw/装配体22.x_t) |
| 齿条、齿轮与其余零件 | [CAD 与交换模型目录](model/Adams%20大作业/sw/) |
| 仿真目标与待补参数 | [重建检查指南](docs/model-notes.md) |

1. 下载完整仓库，在 SolidWorks 或兼容软件中打开装配体，确认零件引用、轴线、啮合方向及几何参数。
2. 在 MSC ADAMS 中导入 Parasolid 模型，设置单位、材料、质量与惯量。
3. 按机构自由度建立固定副、转动副和移动副，再设置接触与 STEP 驱动函数，检查驱动起止过程的连续性。
4. 运行后检查齿条行程与末端转角的对应关系，记录驱动力及约束反力曲线，再判断是否达到翻转目标。
