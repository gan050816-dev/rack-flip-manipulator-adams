# 翻转机构与 ADAMS 重建检查指南

机构通过齿条与直齿轮把直线运动转换为转动，再由锥齿轮改变传动方向，带动末端翻转。原工程记录的目标动作为约 **180° 翻转**，重点观察齿条行程、末端转角和驱动力之间的关系。

公开成果是 CAD 装配、主要传动件和 Parasolid 交换模型，可用于查看结构与准备重建。本页按这些资料整理重建检查顺序；完整 ADAMS 数据库未公开，文中不提供未经核对的驱动、接触或动力学参数。

## 先查看机构结构

| 内容 | 入口 | 查看重点 |
| --- | --- | --- |
| 整体装配 | [装配体22.SLDASM](../model/Adams%20大作业/sw/装配体22.SLDASM) | 齿条、传动轴、齿轮与末端之间的装配关系 |
| 整体交换模型 | [装配体22.x_t](../model/Adams%20大作业/sw/装配体22.x_t) | 导入 ADAMS 前核对零件位置与几何方向 |
| 零件与其他装配 | [sw 目录](../model/Adams%20大作业/sw/) | 齿条、直齿轮、锥齿轮和支撑件的几何 |

传动链为：**齿条直线移动 → 直齿轮转动 → 锥齿轮传动 → 末端翻转**。先沿这条链识别每个零件的运动方式，再建立关节与驱动，可减少把本应转动的零件固定、或给同一自由度重复施加约束的问题。

齿条行程与末端转角的关系取决于实际齿轮几何和传动比，不能只按“180°”目标反推任意驱动行程。几何参数应从 CAD 中读取并复核，文件名不替代尺寸检查。

## 重建前需要补齐的数据

CAD 和 Parasolid 主要提供几何信息。下列设置需在重建时确认并记录，当前公开说明没有足够数据恢复原工程的全部仿真配置。

| 项目 | 需要确认和记录的内容 |
| --- | --- |
| 单位与惯性 | 长度、质量、时间单位；各刚体材料、密度、质量、质心和惯量 |
| 约束映射 | 哪些部件固定；每个移动副、转动副连接的两刚体、轴线方向和位置；初始装配状态 |
| 传动关系 | 齿轮模数、齿数、压力角、啮合方向，以及齿条与齿轮、两锥齿轮的对应关系 |
| 接触设置 | 参与接触的几何对、接触刚度、阻尼、摩擦及所用单位；是否与其他传动约束重复 |
| 驱动函数 | 被驱动的自由度、起止时间、初末位移或转角、STEP 函数及运动方向 |
| 求解与输出 | 重力、仿真时长、输出步长和求解设置；齿条位移、翻转角、驱动力、约束反力的测量定义 |

这些是待补信息，不是可直接套用的参数表。完整数值未核对前，不声称能够复现原工程的力、误差或运动平稳性结果。

## 建议的重建顺序

1. **打开装配。** 在 SolidWorks 或兼容 CAD 中检查零件引用、齿轮与齿条几何、转轴方向及初始位置。
2. **导入几何。** 将整体 Parasolid 模型导入 MSC ADAMS，统一单位并核对零件位置，再设置材料和惯性属性。
3. **建立运动关系。** 按上表记录固定副、移动副、转动副的连接关系，检查自由度，再设置传动或接触关系，避免约束重复。
4. **设置驱动。** 明确输入施加在齿条还是其他自由度，记录驱动函数的单位与起止值，并检查起停过程的连续性。
5. **运行并记录。** 保存重建参数和求解设置，输出齿条位移、末端翻转角、驱动力与约束反力曲线，结合运动过程检查是否达到目标。

若出现异常，先核对单位、自由度、轴线方向和初始干涉，再检查接触及求解设置。不要用随意增大驱动力或接触参数来代替问题定位。

## 如何判断结果

- **运动关系：** 齿条运动方向与末端翻转方向是否符合传动链，位移和转角是否连续。
- **目标动作：** 末端是否达到约 180° 的目标；以本次输出角度和测量定义为依据，另行记录误差。
- **受力表现：** 驱动力和约束反力曲线是否出现异常突变，突变是否对应接触、起停或约束问题。

目前仓库未附可直接运行的 ADAMS 数据库和可复核的动力学曲线，本次整理也未执行重建求解。需要以上述流程得到并保存新的结果，才能讨论具体精度与受力指标。
